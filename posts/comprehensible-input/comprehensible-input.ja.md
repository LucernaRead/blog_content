おそらく何らかの形でこの助言に出会ったことがあるはずです。ドリルをやめて、理解できるものを読んだり聞いたりすれば、言語は後からついてくる。その助言が指す素材の名前が、理解可能なインプット（comprehensible input）です。この言葉はオンラインでは緩く使われ、簡単なコンテンツ全般を指すこともあります。本来の意味はもっと狭く、その狭い意味こそが本を選ぶときに役立ちます。

これは概念を扱う土台記事です。用語の由来、i+1 という式が本に実際に何を求めるのか、そして1ページがあなたを教えるためにはどれくらい知っている必要があるのかを説明します。読書習慣を作る具体的な方法は[読書で言語を学ぶ](https://lucernaread.com/landing/blog/how-to-learn-a-language-by-reading)ガイドにあり、この記事はその下にある考え方だけを扱います。

## 理解可能なインプットとは

理解可能なインプットとは、まだ習得していない言語を含んでいても、学習者が理解できる言語のことです。メッセージが追えます。誰が何をしたのか、次に何が起きたのか、話し手が何を望んでいるのか。新しい単語や形は少しあり、周囲の文章と状況、すでに知っていることがその先へ運んでくれます。

Stephen Krashen はこの考えを *Principles and Practice in Second Language Acquisition*（1982）で示し、*The Input Hypothesis*（1985）で発展させました。彼の説明では、学習者はメッセージを理解することで言語を習得し、教える役割を果たすのはインプットです。ルールの学習は彼のモデルでは別の、より小さな位置にあります。学んだ知識は産出を推敲できますが、土台の能力を作るのは理解されたインプットです。

彼の定式化には見落としやすい条件が二つあります。インプットは理解されなければならないこと。当たり前に聞こえますが、善意の「浴びるだけ」の多くを除外します。そして十分な量があること。理解できた1ページは出来事ですが、理解できた数百ページは方法です。

---

## i+1：今のレベルの少し先

Krashen は目標を **i+1** と書きました。*i* は現在のレベル、*+1* はその一歩先の言語です。追える文の中にある新しい単語、会ったことはあるがまだ自分のものになっていない時制の馴染みの動詞、といったものです。

この式はよくある二つの失敗を同時に説明します。すべて既知の i+0 の素材は滑らかに読めますが、ほとんど何も教えません。レベルをはるかに超えた素材は実質 i+5 で、メッセージ自体が届かないため、もはやインプットではありません。どれほど良いページでも、追えなければ教えることはできません。

実際には i+1 は本を買う前に測れる量ではありません。あなたの脳が次に準備できている構造を正確に指し示すことは誰にもできず、Krashen 自身の主張は、指し示す必要はないというものでした。インプットが理解され、量が十分であれば、次の段階は素材自体が、準備ができた順序で大まかに供給してくれるからです。読者にとっての実務的な翻訳はもっと単純です。物語がはっきり追えて、新しい言語が洪水ではなく細い流れで届く本を選ぶことです。

## 文章のどれくらいを知っている必要があるか

読書研究はこの式に、大まかな数値の目安を与えています。**カバレッジ（coverage）**、つまり文章中の延べ語数のうち、すでに知っている語の割合です。

- Batia Laufer の1989年の研究は、学術的な読解が十分と言える閾値を約 **95% のカバレッジ** としました。この水準では、努力と辞書などの支援があれば文章を追えます。
- Hu と Nation（2000）は設定したカバレッジで読者をテストし、80% では誰も十分に読めず、90% と95% でもできたのは少数でした。支援なしの楽しみのための読書については、約 **98% のカバレッジ** という数字を示しました。

98% は厳しく聞こえますが、換算すれば分かります。250語のページでは、98% は未知語が約5語ということ。95% では12〜13語、つまり文の半分ごとに1語ほどで、95% が作業に感じ、98% が読書に感じられる理由です。グレーデッドリーダーは、あなたをこの範囲の上端近くに保つために存在します。その統制された語彙は、開く前に設計されたカバレッジなのです。

カバレッジは目安であり、関門ではありません。馴染みの物語、よく知る主題、絵や文脈は、これらの数字より低い文章でもあなたを支えますし、抽象的な文章は数字より上でも打ち負かします。これらの数字はサンプルを判断するために使います。次節はそこから始まります。

## 自分のレベルに合ったインプットの見つけ方

レベルが正直に表示されている場所から始めましょう。グレーデッドリーダーは語数とレベルを公表しているため、どの言語でも最初の棚が最も見つけやすいインプットです。フランス語から日本語、中国語までの私たちの言語ガイドがすべてそこから始めるのはそのためです。

その先では、カバーの印象より長く理解可能なままである出典が三つあります。

- **すでに知っている本。** 自分の言語で読んだ小説は、筋があらかじめ理解されています。既知の物語が文脈のすべき仕事をするため、言語は一歩難しくても大丈夫です。[すでに知っている本を読み直す](https://lucernaread.com/landing/blog/reread-a-book-you-know-foreign-language)ことが有効なのも同じ理由です。
- **シリーズを順番に。** シリーズの1冊目は登場人物、舞台、お気に入りの語を教えてくれます。3冊目までには、語彙の多くが繰り返されるため、その作者はあなたにとって最も読みやすい作者になっています。
- **知っている主題のノンフィクション。** 主題の知識は、言語がまだ与えていない意味を補います。自分の仕事や趣味についての本は、馴染みのない世界の小説より丸一レベル早く理解可能になります。

どの出典でも、カバレッジの考え方で試してください。途中のページを開いて読む。何が起きたか言い直せて、未知語がたまにしかなければ、その本はインプットです。一語ずつページを組み立てているなら、それは小説の服を着た教科書の練習で、一日の別の時間のものです。

## 読書での使い方

理解可能なインプットがあなたに求めることは、ほとんどの学習法より少なく、その中心は抑制です。

まずメッセージのために読んでください。物語を追い、文が未知語なしでも通じるなら、その語は通してください。多くの語は戻ってきます。本の中で6回出会った語は、引いたことがなくても終わる頃には自分のものになっていることがよくあります。

引くのは妨げになる語だけです。何度も戻ってくる語、場面全体がかかっている語。そのバランスは[読書中にすべての単語を引くべきか](https://lucernaread.com/landing/blog/should-you-look-up-every-word-when-reading)ガイドの主題です。検索はどれも、インプットを機能させる流れからの小さな引き出しです。本当に意味が止まっている場所に使ってください。

量を保ち、レベルには正直に。インプットは蓄積で効くため、[多読](https://lucernaread.com/landing/blog/intensive-vs-extensive-reading)と自然に組み合わさります。理解できる文章を大量に、楽しみのために、毎晩続けられるペースで読むことです。本が3回続けて苦闘になるなら、レベルを一段下げることは後退ではなく、方法が設計どおりに働いていることです。

自分がファイルとして所有する本については、[Lucerna](https://lucernaread.com/landing/en) は使用権のある EPUB、PDF、TXT ファイルを取り込めるリーダーアプリです。Lucerna は書籍を提供しません。セッション中は単語を引いたり、文の分析を頼んだり、繰り返し出る語を保存したりできます。AI 機能はあなた自身の API キーを使い、プロバイダの料金がかかる場合があり、デスクトップ版はローカルモデルにも対応します。無料ゲストは本1冊と単語5個の保存、無料アカウントは本5冊と単語200個の保存ができます。

## この考えが主張しないこと、争われている点

Krashen の強い版は、理解されたインプットは必要であるだけでなく十分である、習得はインプットだけで進む、と言います。この強い主張こそ争われている部分です。Merrill Swain を含む研究者たちは1980年代以降、言語を産出すること、話し、書き、正確さを求められることが、インプットにはできない仕事をすると主張し、後の研究は相互作用や新しい形に気づくことの役割を加えました。インプットが不可欠であることを争う研究者はほとんどいません。争いは、それがすべてかどうかです。

読者にとっての実務的な落ち着きどころは地味です。代わりになる方法がないため、理解できるインプットを大量に中心に学習を組み立ててください。その上で、話すこと、書くこと、時々の精読を、読書が残す部分を覆う補足として扱い、インプットにすべての仕事を一人でさせることはしないでください。

## 理解可能なインプットについての質問

### 理解可能なインプットは、ただ簡単なコンテンツのことですか？

いいえ。新しいものが何もないコンテンツは理解可能でも i+0 に留まります。教えるインプットは現在のレベルより一歩上にあり、全体として理解できながら、まだ習得していない言語を含んでいます。

### 本が自分のレベルに合っているか、どう分かりますか？

途中のページを読んでください。言い直せて、未知語がたまにしか、1ページに数語程度しかなければ合っています。何が起きているか見失うなら、カバーに何とあっても今はレベルを超えています。

### 完全な初心者でも使えますか？

はい、最小の規模で。初級グレーデッドリーダー、絵に支えられた物語、最初の数百語のために書かれた文章は、i がほぼゼロの学習者のために設計されたインプットです。母語話者の大人向けの小説は、どれほど辛抱してもそうではありません。

### 動画を見ることも数えられますか？

言われていることが理解できれば、数えられます。学んでいる言語の字幕は音と文字を結びつけます。自分の言語の字幕は、物語は追えても新しい言語が処理されずに流れていくことがよくあります。判定はページと同じです。メッセージは届きましたか？

*2026年10月16日に確認した出典：入力仮説と i+1 については Krashen『Principles and Practice in Second Language Acquisition』（1982）と『The Input Hypothesis』（1985）。95% カバレッジの閾値については Laufer（1989）。支援なし読書の98% の数字については Hu と Nation（2000）。カバレッジの数字は研究結果であり、個々の読者や文章への保証ではありません。*
